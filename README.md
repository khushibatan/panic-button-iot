# Panic Button IoT

An ESP8266-based panic button that sends Telegram alerts when pressed.

## Features
- Emergency push button
- Telegram notifications
- Buzzer alarm
- LED indicator
- Wi-Fi connectivity

## Hardware Used
- NodeMCU ESP8266
- Push Button
- LED
- Buzzer

## How It Works
When the panic button is pressed:
1. The buzzer sounds.
2. The LED turns on.
3. A Telegram message is sent to the configured chat.
